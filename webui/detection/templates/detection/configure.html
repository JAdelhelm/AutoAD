Duplicates

A KNN with 2 neighbours scores every row against the others: each row is its own first neighbour, so the score is the distance to the closest other row, and a low score marks a duplicate. ID-like, constant and ignored columns are not compared, so rows that differ only in an order number count as duplicates.
